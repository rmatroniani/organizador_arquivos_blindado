# organizador_arquivos_blindado

## Português (Brasil)

Script em Python para organizar arquivos e pastas em disco.

### Aviso importante

Este projeto está em fase de testes e pode apresentar comportamentos inesperados.

Não há garantia contra perdas, exclusões, movimentações ou alterações indesejadas
nos materiais e arquivos processados. Use o script por sua própria conta e risco.

Antes de executá-lo, faça um backup dos arquivos importantes e, de preferência,
teste-o primeiro em uma cópia dos dados.

## English

Python script for organizing files and folders on disk.

### Important notice

This project is currently in the testing phase and may behave unexpectedly.

There is no guarantee against loss, deletion, relocation, or unwanted changes to
